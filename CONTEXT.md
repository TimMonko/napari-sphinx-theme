# napari-sphinx-theme

A Sphinx theme carrying the napari visual identity and the unified napari.org
site search.

## Language

**Search provider**:
The theme setting that chooses the search implementation: `sphinx` (Sphinx's
built-in search, the default) or `pagefind` (the unified Pagefind-based search).
_Avoid_: search engine, search backend

**Pagefind bundle**:
The `/pagefind/` directory generated by running the Pagefind CLI over a site's
built HTML — it holds the search index, the WASM search engine, and the Pagefind
UI assets. It only exists after the CLI has run.
_Avoid_: search index (a sub-part of the bundle)

**Sibling site**:
Another napari.org sub-site whose Pagefind bundle can be merged into this site's
search results.
_Avoid_: sub-site (the deployment path, not the search relationship)

**Canonical merge list**:
The single maintained list of sibling sites' Pagefind bundle paths, shipped as
`napari-sites.json` beside the search installer. Every adopting site merges from
this one list; there is no per-site curation.
_Avoid_: merge paths, `data-merge-paths`

**Per-index resilience**:
The search installer's behavior of catching a failed sibling bundle and dropping
only that site from results — what makes including not-yet-opted-in sites in the
canonical merge list safe.
_Avoid_: graceful degradation (the general principle; this is the mechanism)

**Search installer**:
The script shipped by the theme that mounts and configures the Pagefind Component
UI on a site: loads the local Pagefind bundle, configures the unified instance
(bundle path + canonical merge list), mounts the search modal, and applies napari
branding.
_Avoid_: PagefindUI wrapper

**Search scope**:
A site searches its own current version's bundle and merges every sibling site's
stable version; it never merges another version of itself.
_Avoid_: —
